## 2. 画面構成

| パス | 画面 | 内容 |
| --- | --- | --- |
| `#/` | エディタ | 画像読み込み、プレビュー、エフェクトの追加・調整、保存 |

### エディタのレイアウト（v0.2.0〜 Google フォトの編集画面を参考）

PC・スマホ共通の 1 画面構成で、ページ全体はスクロールしない。

```
┌──────────────────────────────┐
│ ✕(画像クリア)   ↶ ↷      [保存] ⋮ │ ← 上部バー（⋮: 画像を変更 / 設定 / ヘルプ）
├──────────────────────────────┤
│                              │
│      画像（長押しで元画像）       │ ← 画面の大部分
│                          [≡] │ ← 重ねたエフェクト一覧ボタン（件数バッジ）
├──────────────────────────────┤
│  下部ナビゲーション（3 段構え）       │
└──────────────────────────────┘
```

#### 下部ナビゲーション（3 段構え）

| 段 | 表示 | 操作 |
| --- | --- | --- |
| 1. グループ | カテゴリのアイコン（パターン / ゆがみ・ずれ / オーバーレイ / カラー） | タップで 2 段目へ。かかっている数をバッジ表示 |
| 2. エフェクト | 読み込んだ画像にエフェクトをかけたサムネイル | ← で 1 段目へ。タップで 3 段目へ（未適用なら追加、適用済みならそのレイヤーを編集） |
| 3. 操作パネル | ✕ / 名前 / 複製 / 削除 / ✓、設定項目チップ、選択中の項目の操作部品 | ✓ で確定、✕ で編集開始時点まで取り消し |

- 1・2 段目は横スワイプで移動できる。はみ出す側の端をフェード、下に位置インジケーター、マウス環境では矢印ボタンを表示する（`ScrollRow`）
- 3 段目は設定項目を 1 つずつ切り替えて表示し、画像を隠さない。部品はパラメータの型から自動で選ぶ
  - `range` → スライダー / `select`・`boolean` → チップ / `color` → プリセット色＋自由選択 / `seed` → 「ランダムを変える」
  - 全エフェクト共通の「強さ」「重ね方」も末尾のチップから操作できる

#### 重ねたエフェクト（レイヤー一覧）

画像右下のボタンからボトムシートで開く。並べ替え（ドラッグ）、一時的に隠す、外す、すべて外す。
項目をタップするとシートを閉じてそのエフェクトの操作パネル（3 段目）に移動する。

#### その他

- 画像の長押し（約 0.2 秒）で元画像を表示。初回だけ案内を表示する
- 画像のクリア時は確認ダイアログを出す。エフェクト構成は残る

## 4. 描画パイプライン

```
元画像 ─(縮小: プレビュー画質)→ プレビュー用ソース
        └ レイヤー1 → レイヤー2 → … → 表示

元画像 ─(最大サイズで縮小)→ 書き出し用ソース
        └ 同じレイヤー構成 → PNG / JPEG / WebP
```

- **相対単位**: サイズ系パラメータは「画像の短辺 / 1000」を 1 とする単位で扱う（`env.unit`）。
  これによりプレビュー（縮小）と書き出し（原寸）で見た目が一致する
- **シード付き乱数**: ランダムな要素は `seed` パラメータから作った乱数（`env.rng`）を使う。
  同じ設定なら何度描画しても同じ結果になる
- **プレビューのキャッシュ**: 途中までのレイヤー構成が前回と同じなら、その結果を再利用して変更のあった層以降だけ再計算する
- 読み込み時に 1600 万ピクセルを超える画像は縮小する（iOS Safari のキャンバス上限対策）

## 5. エフェクトの追加方法（拡張ポイント）

`src/effects/defs/` に 1 ファイル追加するだけで、エフェクト一覧・追加ダイアログ・設定 UI・ヘルプに自動で反映される。

```ts
import type { EffectDefinition } from '../../core/types';
import { cloneCanvas, get2d } from '../../core/canvas';

const myEffect: EffectDefinition = {
  id: 'myEffect',          // 保存データのキー。後から変えない
  name: 'マイエフェクト',
  description: '説明文（追加ダイアログとヘルプに表示）',
  category: 'overlay',     // pattern | distort | overlay | color
  order: 10,               // カテゴリ内の並び順
  params: [
    { key: 'size', label: '大きさ', type: 'range', min: 1, max: 100, default: 20 },
    { key: 'color', label: '色', type: 'color', default: '#ff0000' },
    { key: 'seed', label: 'ランダム', type: 'seed', default: 1 },
  ],
  render(input, params, env) {
    const out = cloneCanvas(input);  // input は書き換えない
    const ctx = get2d(out);
    // env.unit, env.rng を使って描く
    return out;
  },
};
export default myEffect;
```

パラメータの型: `range`（スライダー）/ `select`（短い選択肢はトグル、長いものはプルダウン）/ `color` / `boolean` / `seed`（「ランダムを変える」ボタン）。
`visibleWhen` で他のパラメータに応じた表示切替ができる。

保存済みのパラメータはスキーマに合わせて自動補正される（`sanitizeParams`）ので、パラメータの追加・削除をしても古い保存データで壊れない。

## 6. 技術構成

| 分類 | 採用 | 理由 |
| --- | --- | --- |
| ビルド | Vite | 高速、静的サイトとして GitHub Pages に出しやすい |
| 言語 | TypeScript | エフェクト定義・パラメータの型安全 |
| UI | React + MUI（Material UI） | マテリアルデザインの部品が揃っている。テーマで M3 風に調整 |
| 状態管理 | Zustand（persist） | 小さく単純。設定と構成を localStorage に保存 |
| ルーティング | React Router（HashRouter） | GitHub Pages 対応 |
| 並べ替え | dnd-kit | タッチ・キーボード対応のドラッグ＆ドロップ |
| 描画 | Canvas 2D | どのブラウザでも動く。重い処理は将来 Worker / WebGL へ |
| テスト | Vitest | Vite と設定共有 |
| CI/CD | GitHub Actions | `main` への push でテスト → ビルド → Pages 公開 |

### ディレクトリ

```
src/
  core/        型定義・パイプライン・乱数・パラメータ補正（UI に依存しない）
  effects/     エフェクト登録（index.ts）と各エフェクト（defs/*.ts）
  store/       Zustand ストア（エディタ状態・設定）
  components/  UI 部品（editor/ はエディタ画面の部品）
  pages/       エディタ / 設定 / ヘルプ
  lib/         画像読み込み・書き出し・サンプル画像
```

## 7. 保存されるデータ

| キー | 内容 |
| --- | --- |
| `tamani-effect:settings` | 設定 |
| `tamani-effect:editor` | エフェクト構成（レイヤー）のみ。**画像は保存しない** |

## 8. 今後の予定（候補）

優先度は公開後に触ってみて決める。

- エフェクト追加: スクリーントーン、ハーフトーン線、ネオン発光、ぼかし・グロー、ポスタリゼーション、紙テクスチャ、VHS/ブラウン管、枠線（フチ取り）、万華鏡、波ゆがみ

- 重いエフェクトの Web Worker / WebGL 化
- PWA 化（ホーム画面に追加・オフライン対応）
- 多言語対応（i18n）
